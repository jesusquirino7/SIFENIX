# sitio-distribuidor

Sitio web del distribuidor autorizado de refacciones de automatización — catálogo de marcas + formulario de contacto/cotización.

Construido con [Next.js](https://nextjs.org) (App Router) y [Tailwind CSS](https://tailwindcss.com).

## Primeros pasos

Instala las dependencias (esto descarga Next.js, React y Tailwind — solo hace falta internet normal, no necesitas nada especial):

```bash
npm install
```

Corre el servidor de desarrollo:

```bash
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador. Cada vez que guardes un archivo, la página se actualiza sola.

## Estructura

- `src/app/page.js` — página de inicio
- `src/app/layout.js` — layout compartido (título del sitio, fuente, etc.)
- `src/app/globals.css` — estilos globales y Tailwind
